📌 项目简介
---
数字电路课程学习小程序是一款为深圳大学数字电路课程设计的教学辅助工具，覆盖从预习 → 练习 → 测试 → 错题本 → 教师端管理的完整学习链路。

本项目由我主导约 80% 的研发工作，包括：

全流程 产品设计（需求梳理、流程图、信息架构）

小程序 界面设计与交互体验规划

前端开发（微信小程序）

后端开发（Node.js + Express）

数据库结构设计（SQLite）

部署与运维（Render）

目前整体框架与核心功能均已实现，数据库正在持续填充（题库、解析、标签体系等），并预留可扩展接口，后续将接入 AI 辅助讲解与智能练习模块。

🎯 核心功能
🧩 学生端
---
预习模块
课程重点、基础概念、示例动画（预留扩展多媒体内容）。

练习模块
支持选择题、判断题等多题型；即时反馈；记录答题结果。

测试模块
定时、限题量的模拟测试；自动评分；试卷回顾。

错题本
自动收集错题；可按知识点复习；支持跳转解析。

数据统计（基础版）
展示本周/累计的学习量、正确率趋势等。

📊 教师端
---
班级数据统计
查看学生学习情况、各题难度、知识点正确率。

题库管理（开发中）
支持添加、修改、审核题目内容。

日志与版本管理
用于跟踪更新与调试记录。

🔧 后续扩展（已预留接口）
---
AI 自动解析生成

AI 智能推荐练习

AI 辅助电路仿真与可视化

📦 本地运行（开发者）
1. 克隆项目

2. 启动后端
cd backend
npm install
node server.js

3. 配置小程序端

在 /frontend/utils/config.js 修改后端地址：

export const BASE_URL = "http://localhost:3000";

4. 打开微信开发者工具

导入 frontend/ 文件夹即可预览与调试。
